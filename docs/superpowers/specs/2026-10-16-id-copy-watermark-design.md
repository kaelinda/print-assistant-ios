# 身份证复印水印设计

## Goal

在身份证复印流程中增加可编辑的水印文字，默认填入“此证件仅用于 xxxx”，并将水印同时呈现在排版预览和最终生成的 A4 PDF 上。

## Recommended design

`IDCopyDraft` 增加 `watermarkText` 字段，默认值为本地化字符串“此证件仅用于 xxxx”。默认值只在新建 draft 时注入，并会随正反面重拍和导航继续传递。身份证拍摄流程继续只负责收集正反面图片；进入“身份证排版”页面后，用户可以在单行输入框中修改或清空水印文字。输入限制为最多 40 个字符，空白文本视为空水印；输入框提供可访问标签。

排版页由 draft 初始化本地编辑状态，点击“生成 A4 PDF”时将裁剪后的文本写回新的 draft，再导航到生成页，确保值类型 route 不会丢失用户修改。预览在 A4 页面上显示与 PDF 相同的斜向重复水印图案。

生成服务继续生成单页 A4 PDF，并在两个证件图像绘制完成后绘制水印层。水印采用 PDF 页面坐标绘制，使用系统字体、24 pt、灰色 18% 不透明度、逆时针 18°，按 240 pt 横向间距和 170 pt 纵向间距覆盖页面。文本为空或只包含空白时跳过绘制。现有 ID-1 实际尺寸、页面尺寸、文件入库和导航流程保持不变。

## Data flow

1. `IDCopyDraft` 创建时带有默认水印文字。
2. `IDCopyLayoutView` 绑定水印文本并负责预览。
3. `IDCopyGeneratingView` 将包含水印的 draft 交给 `PDFDocumentService`。
4. `PDFDocumentService` 把水印写入 A4 页面，生成的 PDF 仍为一页。

## Validation

- 单元测试验证默认水印、空白归一化、修改/清空水印状态，以及带水印 PDF 与无水印 PDF 的渲染结果存在可见差异；不依赖 PDFKit 对绘制文本的字符串提取。
- 现有身份证 PDF、几何和 UI 流程测试继续通过。
- 在 iOS 模拟器上构建并运行 `PrintAssistant`，确认水印输入和排版预览可见。

# Print Assistant 完整产品状态与 App Icon 设计

## 目标

把 Figma Page 01 中尚未落地的产品状态补齐到可发现、可操作、可恢复的 SwiftUI 流程，并为 App 接入一套与 Liquid Glass 视觉一致的图标资源。

## 范围

### 页面与流程

- 模板中心、模板编辑、模板套用文件选择。
- 批量文件选择、批量处理进度、批量完成。
- PDF 压缩、PDF 密码保护、密码校验错误。
- 证件照来源、裁剪对齐、生成完成。
- 图片导出。
- 设置、隐私与数据、隐私政策、意见反馈、清除索引确认。
- 主流程的空状态、错误状态、处理中状态和恢复入口。

### 系统承接

相机、照片选择器、文件选择器、分享、打印和键盘继续使用 iOS 原生系统界面；应用负责提供一致的入口、标题、状态反馈和返回路径。

### 图标

图标采用扫描取景框、折叠纸页和打印辅助的抽象组合，使用浅色底、深色底和单色着色三种资源。图形保持小尺寸可辨识，避免细线、文字和复杂渐变。

## 架构

- 在 `AppModel.Route` 中增加页面路由和携带必要数据的草稿类型。
- 新增功能域 View 文件，复用 `GlassCard`、`GlassActionRow`、`GlassSearchField` 和 `PrimaryActionButton`。
- 将压缩、保护、图片导出、模板保存接入现有本地文件服务与 `DocumentLibrary`。
- 所有异步操作使用显式 `isWorking` 或局部状态，按钮进入 processing 后忽略重复点击。
- 对失败状态保留输入草稿，并提供重试、返回和分享等恢复出口。

## 验收

- 所有新增入口能从“工具”或“文件详情”发现。
- 每个新增流程至少覆盖成功、空内容、处理中和失败后的恢复路径。
- 单元测试覆盖模板持久化、批量任务状态、导出文件登记和保护文件登记。
- UI 测试覆盖新增入口和主页面导航。
- Debug 构建、单元测试和 UI 测试全部通过。
- App icon 在模拟器 App 启动页可见，资源目录不包含临时远端 URL。
